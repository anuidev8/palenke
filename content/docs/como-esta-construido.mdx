# Cómo está construido cada módulo

Documentación de **cómo está armado el código real** del MVP (rutas, libs, datos, auth). No son ejemplos inventados: son las rutas y archivos que existen en el repositorio.

## Cómo leer las rutas de código

Los textos como ``src/middleware.ts`` o ``src/app/biblioteca/page.tsx`` son **rutas de archivo dentro del repo GitHub** (`https://github.com/anuidev8/palenke`), no enlaces del sitio `/docs`.

- Supervisión no técnica: use las URLs de producto en [Módulos y URLs](/docs/modulos-y-urls).
- Supervisión técnica: abra el archivo en GitHub tras ser invitada al repo privado (ver [Repositorio](/docs/repositorio-codigo)).
- Ejemplo directo: [src/middleware.ts en GitHub](https://github.com/anuidev8/palenke/blob/main/src/middleware.ts) (requiere acceso).

## Patrón común de casi todos los módulos públicos

1. Página **Server Component** en `src/app/<ruta>/page.tsx`
2. Rol del visitante con `getViewerRoleFromRequest` / `getViewerRequestState` (`src/lib/viewer-server.ts`) → sesión Supabase Auth + fila `public.users`
3. Layout visual `SiteLayout` (`src/components/mock/ui.tsx`)
4. Datos desde Supabase, catálogos en código (`mock-data` / libs de galería), o feeds externos
5. Enlaces con `withRole()` cuando se necesita preservar contexto de rol en query string

**Roles:** `public` | `internal` | `admin`  
**Visibilidad de contenido:** `public` | `internal` | `sensitive`

**Middleware** (`src/middleware.ts`): solo protege `/admin/:path*` y `/api/admin/:path*` (sesión + rol admin). El resto de gates viven en la página (`redirect`, `requireAdmin`, checks de visibilidad).

## Admin — `/admin/*`

| Pieza | Ubicación real |
|-------|----------------|
| Home | `admin/page.tsx` + `AdminLayout` |
| Gate app | `requireAdmin()` (`admin-access.ts`) |
| Gate edge | `middleware.ts` (`/admin/*`, `/api/admin/*`) |
| Actividad | `admin_activity_log` |

Carpetas reales visibles: `documentos`, `solicitudes`, `usuarios`, `dashboards`, `novedades` (noticias/eventos), `alertas`.

Subrutas CRUD reales:

- `documentos/nuevo`, `documentos/[id]/editar`, `documentos/rutas-metodologicas`
- `novedades/noticias`, `novedades/noticias/[id]/editar`
- `novedades/eventos`, `novedades/eventos/[id]/editar`
- `dashboards/nuevo`, `dashboards/[id]/editar`
- `usuarios/nuevo`, `usuarios/[id]/editar`
- `solicitudes/[id]`

Nav oculta hoy, aunque las rutas existen: `accs`, `campanas`, `contenido-visual` (`admin-nav.ts`).  
API admin: `api/admin/visual-content`, `api/admin/visual-content/suggestions` (también protegidas por middleware).

## Capas transversales

- **Auth clients:** `src/lib/supabase/{client,server,service}.ts`
- **Permisos:** `src/lib/auth/permissions.ts`
- **Sesión RSC:** `src/lib/viewer-server.ts`
- **Buckets:** `docs-public`, `docs-internal`, `docs-sensitive`, `mediateca-ubuntu`, `memoria-afroterritorial`, `scita-evidence`
- **DDL:** `supabase/migrations/`
- **Docs Fumadocs:** `content/docs/` → `src/app/docs/[[...slug]]/page.tsx` + `src/lib/source.ts`
