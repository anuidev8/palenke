# Repositorio de código fuente

## URL

**https://github.com/anuidev8/palenke**

## Visibilidad

El repositorio es **privado**.

Para revisar código, estructura de carpetas, migraciones SQL y documentación técnica en Markdown, la supervisión debe ser **invitada por correo electrónico** como colaboradora en GitHub.

## Qué contiene

- Código de la plataforma (Next.js / TypeScript)
- Documentación técnica (`docs/technical/`)
- Migraciones de base de datos (`supabase/migrations/`)
- Pack de formatos finales (`docs/final-formats/`)

## Relación con esta documentación web

Esta sección `/docs` es la vía **legible para no técnicos**.

Mapa de construcción por módulo (rutas y archivos reales): [Cómo está construido cada módulo](/docs/como-esta-construido).

GitHub es la vía **técnica** para transferencia de código y auditoría profunda.
